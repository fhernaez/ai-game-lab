# Rules

1. The game proceeds through rounds: speak → act → referee.
2. Each round, every crew member speaks once in speak order.
3. After the discussion, the trainee proposes a structured action.
4. The referee model returns a verdict; its score is clamped by the rules.
5. The proposed action must be valid for the current state and the role.
6. The game runs for the configured number of rounds.
