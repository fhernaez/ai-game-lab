# AI Team Sports Challenge

## Objective

Two crews compete in a simplified turn-based sport, played as a dialogue: each round the
crew members speak in order, the trainee proposes an action, and a referee model returns
a verdict.

The template intentionally abstracts physical simulation so students can focus on crew
coordination, model parameters, and reading the interaction log.

It can be customized toward football, rugby, tennis, volleyball or another suitable game.
