# Contributing to AI Game Lab

Thank you for your interest in contributing! This project exists to help young
people understand and get involved with AI — theory and practice — and every
contribution moves that mission forward.

## How to contribute

1. **Fork** this repository.
2. Create a **branch** with a short, descriptive name (e.g. `fix-serve-position`).
3. Make your changes, keeping them small and focused.
4. Run the tests (`pytest`) and make sure they pass.
5. Open a **Pull Request** with a clear description of what you changed and why.

We review pull requests with care and credit every contributor.

## Ways to help

- **Educators** — lesson plans, classroom guides, exercises.
- **Developers** — frontend polish, simulation improvements, more LLM providers, tests.
- **AI enthusiasts** — prompt engineering, agent strategies, evaluation ideas.
- **Designers** — player sprites, court visuals, UX improvements.

## Guidelines

- Follow the existing code style and keep changes easy to understand.
- Add or update tests where behaviour changes.
- Keep the educational mission front and centre: clarity over cleverness.
- Do not commit secrets (`.env`, API keys). Use `.env.example` as the template.
